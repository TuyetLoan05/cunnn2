THIỆP CHÚC MỪNG NGÀY 20/10

Cách xem:
1. Mở file index.html bằng trình duyệt trên máy tính hoặc điện thoại.
2. Muốn gửi cho người khác bằng đường link, hãy tải thư mục này lên một dịch vụ host web tĩnh (ví dụ GitHub Pages hoặc Netlify).
3. Sửa lời chúc trong phần <p class="message"> và chữ ký trong <p class="signature"> của index.html.

Trang đã được thiết kế responsive cho điện thoại, có hoa/ cánh hoa rơi và nút lời chúc bất ngờ.
